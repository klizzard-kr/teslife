# Teslife

테슬라에서 받은 주행·충전 기록을 모아, 차계부와 정기관리까지 한 화면에서 보는 개인용 웹앱입니다. 차를 깨우거나 제어하지 않습니다. 현재 버전은 v1.18.0입니다.

## 주요 기능

- 주행 기록과 전비. 주행 상세의 에너지 상세 안에 실내·실외 온도, 설정 온도, 수동 팬이 한 그래프에 있고, 시트·핸들·유리 열선은 그 아래 띠로 있습니다. 속도 그래프는 후진 구간을 구분합니다. 배터리 온도는 그 다음입니다. 공조와 배터리 온도 눈금은 5℃이고, 그래프는 시작과 끝 시각만 있습니다. 그래프 밖을 누르면 말풍선이 닫힙니다
- 충전 기록, 장소, 단가. 충전 전력 그래프의 맨 위는 항상 그 충전기 정격이고, 충전기가 없으면 실제 최대 전력입니다. 선 아래는 옅은 초록으로 칠합니다. 배터리 온도는 따로 봅니다
- 충전 탭의 시간별·모드별 사용. 배터리가 오른 시간은 충전 색이고, 오르지 않은 시간에 주행이 있으면 주행 색, 없으면 주차 색입니다. 시간별 충전량은 겹친 충전 기록을 나눈 값입니다. 말풍선은 카드 안에 있고, 그래프 밖을 누르면 닫힙니다
- 차계부
- 정기관리와 타이어
- 알림
- 기간별 통계

## 필요한 것

- Python 3.11 이상
- 추가 패키지는 없습니다. 표준 라이브러리만 사용합니다.

## 설치와 실행

저장소를 받은 뒤 그 폴더에서 실행합니다.

```bash
python -m simulator day | python -m ingest --db signals.db
python -m process --db signals.db
python -m web --db signals.db
```

브라우저에서 로컬 포트 8080으로 엽니다. `--no-seed`를 주면 예시 데이터 없이 시작합니다.

테스트:

```bash
python -m unittest discover -s tests -q
```
